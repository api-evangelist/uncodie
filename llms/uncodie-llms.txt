# Makinari (formerly Uncodie)

> Makinari is an AI-agent business platform: it builds the application a business needs and runs growth on top of it with a team of AI agents (CMO, sales, growth, copywriter, customer support, data analyst, email, WhatsApp, UX) plus a world-class CRM. Programmatic access is via a versioned REST API (API-key Bearer auth), a Content API, Workflows, and an official hosted MCP server exposing 40+ tools. Uncodie rebranded to Makinari; www.uncodie.com redirects to www.makinari.com.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21 (docs.makinari.com/llms.txt returned 404).

## APIs

- [REST API](https://docs.makinari.com/rest-api): Core API — Visitors (tracking/identification), Finder (contact & company search), Robots (browser-automation instances), Instances, Requirements, Secure Tokens. Documented base URL https://api.makinari.io/v1 (live application host: https://backend.makinari.com).
- [Content API](https://docs.makinari.com/content-api): Fetch public site content (blog posts, RSS and other content types) for headless frontends and syndication.
- [Workflows](https://docs.makinari.com/workflows): Automate sequences of actions (lead generation, follow-up, campaigns, deep research, daily stand-ups) executed on Temporal.
- [Agents](https://docs.makinari.com/agents): Per-agent endpoints for chat, CMO, copywriter, customer support, data analyst, email, growth, sales, UX, and WhatsApp agents.
- [MCP Server](https://docs.makinari.com/mcp-server): Official hosted Model Context Protocol server at https://backend.makinari.com/api/mcp with 40+ tools (messaging, leads, content, campaigns, reports, media generation).
