# Makinari (formerly Uncodie)

> Makinari is a revenue-operations platform whose AI agents (CMO, sales, growth, copywriter, customer support, data analyst, email, WhatsApp, UX) build the application a business needs and then run growth on top of it, alongside a CRM and a commerce core. Programmatic access is via a versioned REST API, a per-agent Agents API, a Temporal-backed Workflows API, a public Content API, and an official hosted MCP server exposing 56 documented tools. Authentication is API-key Bearer throughout; there is no OAuth. Uncodie rebranded to Makinari; www.uncodie.com redirects to www.makinari.com.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-08-13. Makinari serves no llms.txt of its own (docs.makinari.com/llms.txt and www.makinari.com/llms.txt both 404 on 2026-08-13).

## What an agent should know first

- Base URL: `https://backend.makinari.com/api`. The documented base `https://api.makinari.io/v1` does NOT resolve in DNS (checked 2026-07-21 and 2026-08-13).
- Auth: `Authorization: Bearer <api-key>` on every call (the MCP server also accepts `X-API-Key`; Secure Tokens uses `x-api-key`). Keys are created per site+user via `POST /api/keys` and expire in 90 days by default.
- No OpenAPI, Swagger, GraphQL or AsyncAPI document is published anywhere.
- No idempotency keys. No published rate limits (a 429 exists with no headers and no numbers). No deprecation policy or Sunset header. No `/.well-known/` document on any host.
- API access is not included on the entry POC plan; it starts at the Startup tier ($99/month).
- Check `https://docs.makinari.com/api/status` before trusting a result — it is machine-readable per-system health, and the Agents API and AI provider systems have been reporting 0% 24h/30d uptime on every pass.

## APIs

- [REST API](https://docs.makinari.com/rest-api): Visitors (tracking/identification), Finder (contact & company search), Robots (browser-automation instances), Instances, Requirements, Secure Tokens. Versioned under /v1.
- [Agents API](https://docs.makinari.com/agents): 48 per-agent endpoints — chat (incl. WebSocket), CMO stand-ups and lead assignment, copywriter content calendar/editor, customer support, data analyst (deep research, segmentation, contact generation), email, growth, sales, UX, WhatsApp.
- [Workflows API](https://docs.makinari.com/workflows): 25 Temporal-backed workflows at `POST /api/workflow/<name>` (leadGeneration, enrichLead, buildCampaigns, deepResearch, dailyStandUp, startRobot…), plus an inbound DB-change webhook.
- [Content API](https://docs.makinari.com/content-api): 14 public GET endpoints (`/api/public/...`) for blog posts, videos, podcasts, social posts, newsletters, case studies, whitepapers, infographics, webinars, ebooks, ads, landing pages, RSS. Browser requests from the registered site domain need no key; server-to-server does.
- [MCP Server](https://docs.makinari.com/mcp-server): official hosted server at `POST https://backend.makinari.com/api/mcp` (JSON-RPC 2.0), 56 tools with published input schemas. Also runnable locally over stdio from the open-source repo (`npm run mcp`).

## The MCP surface is not a mirror of REST

35 of the 56 MCP tools print a REST equivalent on their own docs page. 21 do not — and the entire commerce cluster (quotations, quotation_items, purchases, purchase_items, checkout, catalog_commerce, entitlements, subscription_plan_items, reservations, reservation_schedules) is **MCP-only**. Conversely 119 documented REST operations have no MCP tool. See `mcp/uncodie-tool-crosswalk.yml`.

## Docs

- [First Steps](https://docs.makinari.com/first-steps): account, API keys, project config, requirements, team, inbound/outbound setup.
- [API Keys](https://docs.makinari.com/first-steps/api-keys): create, list, revoke scoped keys (read/write, 90-day default expiry).
- [MCP Tools](https://docs.makinari.com/mcp-server/tools): 56 tool pages, each with an input-schema table and its REST equivalent where one exists.
- [Webhooks](https://docs.makinari.com/mcp-server/tools/webhooks): register `url` + `events[]` (e.g. lead.created, conversation.started). No complete event catalogue and no signature scheme are published.
- [Chat Widget](https://docs.makinari.com/channels/website/setup-chat-widget) and [Tracking](https://docs.makinari.com/channels/website/setup-tracking): the embeddable `window.MarketFit` surface.
- [API Status](https://docs.makinari.com/status): live per-system health and SLA; JSON at `/api/status`.

## Open source

- [makinari.org](https://makinari.org): the open-source hub — three repositories, advertised as AGPL-3.0.
- [Uncodier/API](https://github.com/Uncodier/API): the API server, docs site content and the MCP server (`mcp-server/`).
- [Uncodier/market-fit](https://github.com/Uncodier/market-fit): Growth Engine frontend.
- [Uncodier/workflows](https://github.com/Uncodier/workflows): Temporal workflows and crons.
- [makinary/cli](https://github.com/makinary/cli): one-line installer for the whole local stack.
- Caveat: no repository carries a LICENSE file, all three declare `"private": true` in package.json, and the docs footer says "MIT" while makinari.org says AGPL-3.0. Nothing is published to npm or PyPI — including `@makinari/mcp`, which the company's own developer page shows in a code sample.
